# Moino (墨)

English | [简体中文](README.zh-CN.md)

Moino is a fast, local-first Markdown editor with Typora-style live preview, built with Rust, GPUI and GPUI Kit. Its Chinese name, 墨, means “ink”.

The [product specification](docs/product.md) defines the target scope. Current local contents and engineering prerequisites are described in the [development guide](docs/development.md#工程目录与使用边界); the [roadmap](docs/roadmap.md) defines the implementation order.
