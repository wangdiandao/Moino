# 文档模型

## 文本与位置

权威状态是规范化为 LF 的 UTF-8 文本、修订 `Revision` 与会话内唯一且不变的 `DocumentId`。磁盘原始换行由文件属性保留。块树、内联 token、大纲、统计、搜索和渲染结果均绑定修订，是只读派生数据，不能回写正文。

逻辑位置使用 Unicode 标量。标量、UTF-8 字节、UTF-16 码元通过显式换算互逆；字节用于外部文本组件，UTF-16 用于平台输入法。带单位类型见[编码规范](../coding-standards.md#类型设计)，光标步进见[选择](../modules/selection.md#逻辑选择)。

重新装载文档改变 `Epoch`，区别于逐次提交的修订；旧世代任务按[运行时身份](../architecture.md#运行时模型)拒绝。

## 事务契约

所有内容修改经过 `Transaction`，视图刷新与派生计算不得创建事务。事务包含有序文本编辑和新选择，以编辑前坐标表达、起点降序应用；区间必须不重叠且在文档内，否则整体拒绝，不产生修订。

文档从修订 0 开始，每次成功提交严格加一并返回反向编辑和提交事件，事件包含新修订与受影响标量区间。反向编辑可恢复提交前文本；撤销重做仍递增修订，其分组见[历史](history.md)。`snapshot()` 冻结修订、文本与 CST，可离线读取且不阻塞后续事务。

打开、另存与导入构造新文档，多窗口共享同一文档身份，见[会话](sessions.md)。

## 选择与映射

`Selection` 包含锚点、活动端两个标量位置及端点亲和性。锚点小于活动端为前向，大于为后向，相等为折叠光标。

编辑前方的偏移不变，删除区间内的偏移夹到区间起点；插入点处按亲和性落在新增文本之前或之后。两个端点分别映射，保持锚点、活动端语义，不交换方向。节点身份的生成与复用由[解析器](markdown-dialect.md#增量解析与节点身份)定义。

## 文档不变量

每次提交校验[无损 CST](markdown-dialect.md#cst-与标记区间)、位置换算及节点身份。拼接不一致、换算失败或身份冲突时，停止写入、保护当前权威文本并建立恢复点，不自动保存可能损坏的结构。允许复制与导出文本，提示恢复，错误码为 `model.invariant`。
