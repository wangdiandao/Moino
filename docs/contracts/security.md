# 安全与隐私

## 文档与执行边界

文档、图片、图表、HTML 和导入文件都是数据，不能执行或借此扩大文件授权、启动程序、改配置或发送凭据。不提供任意 shell、脚本、路径或命令执行入口；外部进程只能使用结构化参数、显式超时和最小环境变量。

HTML 净化、容器解包和资源解码持续实施校验与预算，不能因没有网页引擎而省略。显示允许范围见[HTML 与媒体](../modules/html-media.md)，同进程服务的身份校验见[会话](sessions.md)。

## 网络与本地数据

远程资源、词典下载、上传分别授权，不设后台遥测或自动上传。凭据进入系统凭据存储，诊断只保存在本地；设置和文件内容不能扩大权限。

日志不记录正文、完整路径、URL 查询参数、剪贴板和凭据；需要定位文件时用脱敏路径标识。日志结构与级别见[编码规范](../coding-standards.md#日志与隐私)。词典网络请求见[拼写检查](../modules/spellcheck.md#词典分发)。

安全失败保留原文本与可恢复数据，不以隐式降级绕过授权。

安全模式不启动外部处理或加载网络资源，用户主题处理见[主题加载](theme.md#注册表与加载)。
