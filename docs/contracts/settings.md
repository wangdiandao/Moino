# 设置

设置使用 JSONC 和随包 JSON Schema，界面读写同一组文件，不另存数据库副本。有效值从低到高为产品默认、用户、工作区、文件、会话。

| 层 | 来源 |
|---|---|
| 用户 | 平台配置目录 `Moino/settings.json` |
| 工作区 | `<工作区>/.moino/settings.json` |
| 文件 | 文档元数据中明确允许的键 |
| 会话 | 不持久化的临时覆盖 |

保存使用[原子写入](../architecture.md#基础设施)。解析或校验失败只拒绝本次修改，保留上一有效值；组件只读取归一化后的有效对象。设置页显示继承来源，允许范围见各设置的归属正文，完整索引见[预留范围](../planned.md#config-catalog)。

文件层不能开启上传、执行命令或扩大文件权限。可移植导出标识为 `moino-settings`，排除凭据；主题与覆盖由[主题系统](theme.md)定义。键命名见[编码规范](../coding-standards.md#命名)。
