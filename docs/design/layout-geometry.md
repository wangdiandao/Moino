# 布局几何

## 窗口装饰与菜单

默认使用原生装饰，客户区自绘标题区高 0 px。Windows 与 Linux 隐藏菜单以覆盖层出现，不移动正文；自绘标题栏开启后高 28 px，菜单常驻其中。触发与导航见[菜单](../modules/menus-dialogs.md)。

## 正文盒

`content.max_width` 默认 860 px，正文盒内边距为 30 px；1024 / 1200 px 与对应的 30 / 100 px 内边距保留为用户可选档，不随窗口宽度自动跳档。正文盒在主视口内居中，窄窗按可用宽度收缩，保留该档内边距。平面背景见[配色](ink-theme.md#主题族身份)，字体见[排版](typography.md)。

## 编辑表面

专用表面挂载与静态呈现的位置差不超过 1 px，滚动锚点保持不变；表面行为见[代码块](../modules/code-blocks.md#编辑表面)。
