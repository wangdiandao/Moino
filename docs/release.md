# 发布

## 交付物

使用 cargo-packager 经 CI 构建 Windows 按用户安装的 NSIS、MSI，macOS 的 `.app` / DMG，Linux 的 AppImage、deb，随包附 SHA-256 校验值及发布说明。

发布包包含[产品范围](product.md#使用范围)中声明的能力、内置主题、[字体](design/typography.md#字体角色)、离线高亮、数学图表、[随包词典](modules/spellcheck.md#词典分发)、图标和只读用户指南。中日韩系统字体、彩色 Emoji、打印服务列入系统依赖；缺失时按对应后备诊断，核心启动不依赖未说明的下载。第三方与字体许可证文本随包，清单见[参考资料](references.md)。

## 安装与卸载

默认只影响当前用户，不改其他编辑器配置；文件关联由用户主动勾选。卸载保留用户文档、工作区、恢复和设置，清应用数据单独确认并展示范围。目录归属见[架构](architecture.md#关键接缝)，写入权限不足时提供只读或换目录，不提权。

## 版本与签名

版本遵循语义化版本。自 M3 起每个里程碑结束发布 0.x 到 GitHub Releases，具体节奏见[路线图](roadmap.md#里程碑)。预览只交付已完成能力，出现的能力须符合契约，不放占位按钮或伪成功；1.0 实现全部产品范围。

0.x 不签名，发布说明解释 SmartScreen、Gatekeeper 与 Linux 相应提示及处理；1.0 必须完成 Windows 代码签名、macOS 签名与公证。

## 发布门槛

- 全部适用场景、精确向量及[平台手动检查](testing.md#手动验证清单)通过；不适用只限系统原生差异并说明替代路径。
- 没有已知数据丢失、权限越界、保存伪成功或跨文档任务污染；自动保存、恢复、冲突、多窗口经过故障注入。
- [质量目标](planned.md#quality)和无障碍门槛满足，字体与布局可复现，全部导入导出经真实样本验证，安全模式能从主题或设置损坏恢复编辑。
- 正常、异常、取消、竞态、权限受限结果均符合正文；框架名称或实现风格不作为符合性理由，也不能据此改变输入输出、历史、几何和安全语义。

任一门槛未通过不发布。先完成里程碑、打标签并构建，再执行发布检查；失败修复或先修订归属契约和验收后重新构建，禁止只在实现中放宽或隐藏未通过项。
