# 扩展指南

先按[开发流程](../development.md#文档先行工作流)更新所属行为，再做下列改动；步骤引用契约，不在指南另定义默认值和失败规则。文档中源码位置均为目标工程路径。

## 命令

1. 在行为归属正文明确效果、适用上下文、只读和禁用条件，在命令注册表登记元数据及默认快捷键，核对平台保留键。
2. 更新[菜单](../modules/menus-dialogs.md)入口和本地化资源。
3. 业务 crate 实现单一入口，文本修改生成事务；声明对应 action，由处理函数调用该入口。
4. 测试业务逻辑、真实组件派发和禁用状态，文本操作补[精确向量](#验收向量)。

## 块类型

1. 在[方言](../contracts/markdown-dialect.md)定义语法、解析顺序、扩展开关和残缺输入，说明叶块或容器块。
2. 在文档模型与语义中间表示登记结构，在所属模块和导出格式说明交互、转换和降级。
3. 实现 CST 增量边界、模型与编辑规则、块投影及选择映射；能够用 Kit 节点表达就直接复用。
4. 接入源码高亮、统计与各写出器，补一致性、属性和撤销重做测试。

## 设置

1. 在所属正文定义键、值类型、默认值来源、范围、作用域和生效时机，再登记设置索引。
2. 扩展 `moino_settings` 类型和校验，生成 schema；文件层先核对允许列表，界面读写遵循[设置契约](../contracts/settings.md)。
3. 确定设置页分组与顺序，添加本地化；功能代码只读有效对象。
4. 测试默认、越界、作用域、继承来源、导入导出与凭据排除。

## 主题 token

1. 确认已有语义 token 不能表达需求；颜色值只在[配色](../design/ink-theme.md)定义，排版与几何各归其设计正文。
2. 扩展主题类型、内置文件 `assets/themes/moino.json`、schema 与回退，必要时补[Kit 投影](../contracts/theme.md#投影到-gpui-kit)。
3. 检查覆盖合成、高对比、控件命中与两套内置主题，复核配对表；使用方只读有效 token。

## 导出格式

1. 先核对产品范围，定义格式配置、保留内容、转换及降级，在注册表登记命令。
2. 实现[导出契约](../modules/export.md)的写出器，接入导出面板与配置。
3. 用真实样本验证结构、资源缺失、覆盖确认、取消、超时和临时资源清理。

## 代码语言

1. 在[语言注册表](../modules/code-blocks.md#语言)登记语言与别名，映射到 syntect 语法。
2. 将语法作用域映射到现有主题 token，需要新 token 时走上节流程。
3. 检查补全候选、别名、未知语言、信息行与高亮快照。

## 验收向量

1. 在 [YAML](../acceptance/README.md#向量字段)中写唯一行为名称、归属章节与场景，精确保留文本空格及尾换行；时序和几何先明确执行约定。
2. 新场景在[场景矩阵](../acceptance/scenarios.md)登记；正文只引用数据，不复制输入输出。
3. 检查文本、选择、历史、脏状态与持久化副作用。编辑可撤销回初态，重做得到相同结果。
4. 加载器建立后执行[对应检查](../testing.md#ci-门禁)；未实现行为明确跳过并在 Issue 跟踪，不能静默漏载。
