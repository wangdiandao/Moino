# 即时预览验证

M2 使用正式 `moino` 窗口，不使用[基础验证](m0.md#技术原型)的固定样本入口。窗口初始状态按[产品](../product.md#使用范围)，排版按[字体角色](../design/typography.md#字体角色)与[正文盒](../design/layout-geometry.md#正文盒)。

## 自动检查

正式编辑与历史向量通过真实 GPUI 编辑实体执行：字符经原生输入处理器，Enter、删除和 Tab 经键盘，格式命令经 Action，组合经 `TestInput`。完整比较文本及方向选择；不能仅在界面测试中再调用核心解析器后声明向量通过。

源码与即时预览的往返检查同一文档、修订和历史：在一个表面输入，在另一表面撤销与重做；同时覆盖先前输入尚在派生时请求切换，确认不丢失排队输入。源码高亮使用[同一 CST](../modules/view-modes.md#源码模式)。

长文档检查只排版可见叶块、远端插入点可滚入可见区；改变宽度、主题、字号或标记展开后按[滚动保障](../modules/selection.md#滚动保障)保留定位。主题与菜单切换不移动主视口，展开标记的颜色不改变原文坐标或文档修订。

呈现检查逐项覆盖内联标记的进入与离开、嵌套语法、任务状态和方向选择，检查真实投影的文本、样式和坐标。指针检查双击、三击、拖选、Shift+点击扩展与 Ctrl+点击定位；键盘和指针结果均须回到同一逻辑选择，不能只验证输入后的权威文本。

指针按下后先完成展开和重排，再在原坐标发送移动与松开事件，验证单击仍为原逻辑插入点；随后输入不得意外替换字符。另以真实坐标移动验证跨块拖选，不能通过忽略所有移动事件满足单击断言。

标题逐级检查 `#` 前缀输入、空格后的展开、离开后的折叠，以及键盘返回、指针返回和源码模式往返；比较正文与标题的真实文字几何，不仅检查树节点类型或首次折叠。任务项覆盖紧凑、松散、续行和 Setext 标题组合，确保没有空白复选框行或重复标记。

## Windows 原生输入

在正式窗口分别使用拼音、日文与韩文输入，观察候选框跟随插入点并位于当前叶几何附近。检查组合期间正文修订与历史不变，提交只形成一个事务，取消移除临时文本；组合后移动、切换表面、撤销与重做保持内容及选择。还须覆盖 Unicode 代理对、多行组合以及快速普通输入后立即开始组合。

组合态仅替换选择所在区域的显示文本，保留其余块的排版、身份与虚拟化；不得将全文切换为单个源码叶块。组合更新、取消及提交分别检查首个可见块、候选框几何和文档修订，只读文档不显示可写的组合文本。

Emoji 验收使用原生文本输入，覆盖代理对、肤色修饰、家庭 ZWJ 序列和旗帜的整字素移动与删除、源码模式往返及共享历史，不要求系统 Emoji 面板。

受控处理器测试不能替代原生候选窗和系统输入法检查；实际平台、构建、字体与未验证项按[开发交付](../development.md#文档先行工作流)记录在 Issue 或 PR，不写入规格完成度。
