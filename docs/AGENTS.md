# 文档编写

每项要求只在一个正文位置定义，其他页面用说明主题的相对章节链接引用。开头直接说明内容，随后按业务顺序组织；删除只复述范围、泛称验收或罗列相关链接的模板章节，不为每页补齐相同标题。

## 内容归属

| 文档 | 负责内容 |
|---|---|
| 产品 | 用户场景、能力范围、非目标与平台边界 |
| 领域词汇 | 概念含义，不承载操作规则、实现或数值 |
| 架构 | crate 职责、依赖、运行时与跨模块接口 |
| 共享契约 | 数据、事务、生命周期与失效条件 |
| 功能模块 | 用户操作、上下文、结果与失败行为 |
| 设计 | 字体、颜色、几何与时序参数 |
| 验收 | 检查目标与精确数据，链接判定依据 |
| 开发、编码、测试、发布 | 各自工程操作与门槛 |

新选择的结论和必要理由直接融入归属章节，同步接口、数据与引用；不保留独立决策、日期补丁、条款代码和头部元信息。未决细节和没有正文的主题统一在[预留范围](planned.md)登记，正文按需要链接，不反复添加同一段“尚待补全”说明，不凭标题补造默认值。

## 写法

正文使用简体中文，标识符、API 与路径保留英文；术语见[领域词汇](CONTEXT.md)。只有根目录 README 提供内容一致的中英文两份。段落不手动折行，仓库文本使用 UTF-8 与 LF。

“必须”表示不可省略，“禁止”表示不可出现，“允许”只指明确列出的操作。默认值指首次启动且无用户配置的值，未开启选项保留配置但不生效。限定场景优先于通用行为，再应用默认设置；精确向量不能覆盖安全和数据保护条件。冲突通过改正文解决，不由实现者自行择一。

尺寸使用客户区逻辑像素 `px`，时间用 `ms`，容量用 `KiB`、`MiB`、`GiB`。表格用于比较和映射，图用于确有帮助的状态与关系，不重复维护一份图文规则。数值、格式和行为只在所属章节定义，示例引用真实数据。

内部链接必须指向已有文件与锚点；规划路径用代码格式标明。外部来源与许可证见[参考资料](references.md)。实现进度和验证结果不写入规格，工作流程见[开发流程](development.md)，交付检查见[文档验收](testing.md#文档验收)。
