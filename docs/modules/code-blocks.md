# 代码块与专用编辑表面

## 编辑表面

代码、数学和 HTML 块失焦时静态呈现，插入点进入后原位挂载 GPUI Kit `Editor`，同一时刻最多一个活动实例。静态与活动表面的字体、字号、行高、内边距相同，切换保持滚动锚点，位置误差见[布局](../design/layout-geometry.md#编辑表面)。

跨块选择由即时预览处理，块内由活动表面处理。文本经[事务](../contracts/document-model.md#事务契约)写回，保存和导出前提交活动文本；局部历史及退出归并见[撤销](../contracts/history.md#历史边界)。

## 高亮

代码块使用 Kit 的 syntect 和[主题语法 token](../design/ink-theme.md#语法高亮)，超长块在后台按行分批计算，不提供基于语法树的折叠。Markdown 全文高亮由[源码模式](view-modes.md#源码模式)定义。

## 语言

语言与别名只从注册表解释，匹配不区分大小写，信息行保留原写法；补全候选由注册表生成。修改语言只改信息行和呈现，不改代码；未知语言按纯文本显示，不报错。

不加载文档指定的语法执行器。新增语法先检查 Kit 集合，缺失时核对定义和许可证后评审加入；扩展流程见[指南](../cookbook/README.md#代码语言)。
