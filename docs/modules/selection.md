# 选择与标记展开

## 逻辑选择

选择结构与编辑后的端点映射见[文档模型](../contracts/document-model.md#选择与映射)。光标移动和删除以扩展字素簇为边界；上下移动保持首选视觉列，行内图片、数学等原子对象按整体跨越。

Home / End 移到当前视觉行的起点或终点；Primary+Home / End 移到文档起点或终点。附加 Shift 保留锚点并扩展选择。这些导航按输入顺序执行，先提交当前组合文本，再读取前序编辑的结果。

## 标记展开与折叠

插入点所在的最外层内联包裹显示原始标记；非折叠选区由首尾两个端点所在的最外层包裹决定展开范围，中间完整覆盖的其他包裹保持折叠。展开的包裹内所有嵌套标记一起显示。展开不取消正文的粗体、斜体、删除线、高亮、代码、链接或上下标样式；标记使用标记颜色，正文样式不传播到自身外侧的标记。

标题输入区分段落候选与已转换标题。输入中的 ATX 候选保留井号和闭合标记，使用正文尺寸，候选正文加粗；尚未离开时不能因静态 CST 已识别为标题而提前应用标题字号或隐藏标记。Setext 候选保留原始段落和下划线，不套用 ATX 候选装饰。离开候选块、执行结构命令或切换编辑表面时完成块转换；已加载或粘贴的标题及显式标题格式命令直接建立正式标题。

正式标题使用对应等级的[标题排版](../design/typography.md#字体角色)。插入点、选区进入或离开正式标题，以及源码模式往返，均保持标题字号、行高和下划线，不重新展开 ATX 井号或 Setext 下划线；标题内的内联语法仍按内联规则展开。正式标题活动时在行尾显示 `H1`–`H6` 徽记，徽记不占用正文排版宽度。候选状态不显示该徽记。

即时预览的标题命中和 Home 定位到标题内容起点；左右移动跨越隐藏的块标记，不在井号或 Setext 下划线内停留。引用、列表及其续行的隐藏前缀遵循同一定位规则。空标题、空引用和空列表项保留容器样式及可命中的内容插入点。源码模式中的逻辑位置保持原文坐标，返回即时预览后从隐藏标记位置输入时先定位到内容边界，不改写标记。选择全文仍覆盖完整权威文本。

内联标记展开由选择派生，只改变呈现，不产生文本事务。块的候选与正式状态由编辑会话拥有，不能只从当前 CST 或选择反推。候选正式化是独立的可撤销编辑状态变化，保持原文及脏状态不变；撤销返回候选，重做恢复正式块。呈现失败时回落为全文源码显示，保留内容。

终止块的换行及其后的空行不属于该块的展开区域。光标位于标题最后一个字符之后、终止换行之前时仍在标题内；越过换行进入下一行后折叠前一标题，文档末尾的空行也遵循此规则。选区只覆盖终止换行时不展开前一块。

主题分隔线在插入点或选区离开后呈现为横线，进入其源码区间时显示原文；横线保留可命中的叶几何，点击后能定位和编辑，切换不修改权威文本。

## 多击与拖选

编辑器只维护一个连续选区，不提供多光标或多个独立选区。双击选词，三击选块，拖拽选择连续区间；跨块包含完整中间块。Shift+点击保留锚点并扩展到目标；Ctrl+点击与普通点击相同，折叠为目标处的插入点。

单击的逻辑命中在按下时确定；按住鼠标和拖选期间冻结标记展开及候选转换造成的重排，松开后按最终逻辑选择更新。重复收到同一位置的移动事件时保留原选择，实际移动后才扩展拖选；重排后恢复同一逻辑端点，不能重新按旧屏幕坐标命中。

松开后延迟 10 ms 更新内联标记；单击块焦点转换等待总计 180 ms 的多击判定窗口，双击与三击直接提交各自的逻辑选择。新的键盘输入、组合输入或手势取消旧的延迟任务，过期任务不能覆盖新的选择。

## 滚动保障

键盘移动或选择变化后，插入点必须可见，上下各留一行余量。
