# 导出与打印

## 输入与格式

导出从冻结修订的语义中间表示开始，不读可变界面状态，导出期间编辑不进入结果。语义 JSON 的 `format` 为 `moino-document`，PDF 创建者为 `Moino`。

| 输出 | 实现 |
|---|---|
| PDF、PNG、JPEG、打印 | 语义结构转换为 Typst 内容，用工作区固定版本排版 |
| 带主题或无主题 HTML、EPUB、DOCX、ODT、RTF、纯文本、语义 JSON、Markdown 方言 | `moino_export` 写出器 |
| HTML、DOCX、ODT、RTF、纯文本导入 | 同一 crate 的导入器 |

## 分页与主题

PDF 保证分页、孤行寡行控制、重复表头、书签、可搜索文字和字体嵌入。带主题输出将正文 token 映射为 Typst 样式；两套排版引擎以 token 和视觉样例校验一致性，不承诺逐像素相同。不随包依赖外部通用转换程序。

## 提交与打印

活动编辑表面先[提交文本](code-blocks.md#编辑表面)，缺失资源在导出屏障中列出，不静默丢失。写出器只收语义结构和配置；结果先写任务专属临时目录，校验后原子提交。失败或取消清理临时资源，保留旧目标与文档；依赖未就绪的入口显示原因和配置位置。

打印把同一分页 PDF 交给 `moino_platform`，不经过文件预览组件。
