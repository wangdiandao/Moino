# 数学公式

`moino_math` 封装 RaTeX 解析和布局，在 GPUI 原生绘制，导出复用矢量结果。引擎接缝隔离 TeX 能力差异，不引入浏览器或脚本运行时。

## 排版与编号

Moino 计算无编号、所有显示公式编号、编号环境三种模式，以及 `\label`、`\ref`、`\eqref`、显式 `\tag` 和 `\notag`，再交给引擎排版。文档元数据宏、宏展开深度和长度、公式长度都由 Moino 限制。

## 不支持内容

xypic 交换图显示“不支持的环境”诊断并保留源码；physics 宏集可选，默认关闭。其他失败按[错误模型](../architecture.md#错误模型)处理。
