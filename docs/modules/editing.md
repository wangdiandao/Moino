# 编辑

## 输入路由

编辑输入“意图 + 当前选择”，输出[文档事务](../contracts/document-model.md#事务契约)，与视图无关。非法意图（如只读块插入）不产生事务；上下文冲突只取一条规则，不叠加。

- 键盘字符输入按当前块上下文路由：普通块进入文本插入；代码块、数学源码与 HTML 块内进入专用表面（见[专用表面](code-blocks.md#编辑表面)）；专用表面未激活时输入作用于结构层。
- 有选区时输入先删除选区再插入文本，两步合并为一个事务；无选区时输入为单点插入。

已由 CST 识别、尚未闭合而延伸到文档末尾的字面块，其末尾插入点仍属于该字面上下文：输入不触发正文配对，Enter 只插入一个换行。已闭合块的外侧和下一块起点不继承前块的字面上下文；未形成语法节点的残缺前缀仍按普通文本处理。

## Enter

- 段落中按 Enter 在光标处拆分当前块为两个 CommonMark 段落，以空行分隔，光标移到分隔空行之后的新块起点；后续输入仍属于新段落。
- 标题中按 Enter：光标位于标题末尾时退出为同级段落；位于标题中间且后半部非空时拆分为同级标题；位于标题起点时在上方插入新段落、光标留在标题。输入候选先按段落编辑上下文处理，不能把静态解析器产生的标题节点当作已建立标题。
- 空标题的内容起点和末尾重合时，优先按末尾规则退出；ATX（含 Tab 分隔）和 Setext 标题均按标题内容与容器边界执行，不用单行前缀猜测结构。
- 列表项中按 Enter：空项结束当前层列表（项被移除，光标进入紧随其后的段落，保留外层容器）；非空项拆分当前项并创建同级新项，有序列表重新编号。选区替换后拆分也须重编号，只修改同级列表项的编号，不能改写子列表或形似编号的正文。
- 任务项在内容起点拆分时，上方空项取消勾选、下方原正文保留勾选；中间拆分时两半保留原勾选状态；末尾新建的空任务项未勾选。
- 块引用中按 Enter 延续引用行；在引用内空行再按 Enter 退出当前层块引用，保留外层列表或引用。
- 围栏代码块、数学块与 HTML 块内 Enter 按换行处理，不拆块；块尾外侧按 Enter 在下方新建段落。

## Backspace 与 Delete

- Backspace 在段落内容起点并入前一文本块；标题内容起点第一次 Backspace 仅去除标题标记并转为段落，保留正文和外层容器，再次 Backspace 才合并前块。列表项首合并前提升一级。
- Backspace 在语法标记边界（如 `**` 之后、链接括号内）先删除标记而非内容字符；标记全部删除后语法结构消失。
- Delete（前向删除）在文本块内容末尾把下一文本块的正文并入当前块，光标留在拼接点；与段落起点 Backspace 的合并结果对称。合并保留接收块的格式，移除被合并标题的 ATX 或 Setext 标记；普通段落中的标记形似文本不按块前缀删除。
- 跨文本块删除选区时，保留前侧接收块的语义，把后侧未选正文合入接收块，并去除后侧遗留的 ATX 闭合井号、Setext 下划线等块外壳；引用和列表续行按接收容器重新建立前缀。前向与反向选区结果相同，单次撤销恢复文本与方向选择。
- 已勾选任务项在内容起点 Backspace 先取消勾选；引用在内容起点一次退一层。围栏内容起点 Backspace 先将整个块降为段落并移除两端围栏。

## Tab 与缩进

- 列表项中 Tab 提升缩进一级（变为上一项的子项），Shift+Tab 降低一级；缩进按容器宽度对齐，新子有序列表从 1 开始。
- 没有上一同级项时 Tab 不修改文档；根层列表项继续降低一级时移除项标记并转为段落。缩进修改保留逻辑选择及正文内的光标位置。
- 段落与标题中 Tab 按当前设置插入对应宽度的空格或 `\t`；选中多行时 Tab 整体增加缩进。
- 初始缩进单位为四个空格；自动配对初始开启。
- 表格内 Tab 移到下一单元格，末单元格后新建一行；Shift+Tab 移到上一单元格（细节见[表格（预留）](../planned.md#tables)）。

## 交互语法转换

- 行首 ATX 前缀按[方言](../contracts/markdown-dialect.md#基础方言与扩展)识别为标题候选，输入时只装饰候选，离开后建立正式标题，状态及显示见[选择](selection.md#标记展开与折叠)。`-` / `*` / `+`+空格立即建立无序列表；`1.`+空格立即建立有序列表；`>`+空格立即建立块引用；这些容器转换与标题候选不共用一个“语法识别即转换”开关。
- 未完成的前缀保留原字符；编辑缓冲区末尾不伪造空格或换行。围栏、数学和其他原始块使用各自的进入与离开规则，不能通过标题启发式识别。
- 行首第三个反引号触发围栏转换，不依赖自动配对开关；粘贴原文和已提交的输入法组合不触发键盘专属的补闭合围栏操作。
- `==` 触发高亮包围，`~~` 触发删除线包围，`$` 触发行内数学包围（光标置于内部）；输入未配对时按普通文本。
- 转换只发生于行首或块内合适位置；已含语法标记的文本不再二次转换。

## 自动配对与智能标点

- 输入配对符（`(`、`[`、`{`、`` ` ``、`"`、`'`、`*`、`_`、`~`、`$`）时按上下文插入配对并把光标置于中间；在选中内容外输入配对符时改为包围选区。
- 输入右配对符且光标右侧已是同一右符时只移过光标，不重复插入。
- 普通正文的单词内部或词尾输入单引号时，将它作为词的一部分插入，不额外补一个右引号；空白位置的配对和选区包围不受影响。行内代码内容不自动配对，但光标位于已闭合代码的右反引号前时，仍按上一条跳过已有闭符。
- 自动配对开启时，在普通正文的空配对符内部按 Backspace，一次删除左右两符，作为一个可撤销操作；代码等字面内容中的普通括号按字素删除，不推断成配对结构。
- 空标记对内连击优先于跳过右符：`*█*` 与 `~█~` 分别升级为 `**█**`、`~~█~~`；行首空 `$█$` 再输入 `$` 转为上下独占行的数学块，光标位于中间空行。已经升级的双标记不再递归升级。
- 智能标点（弯引号、破折号、省略号转换）默认关闭；开启时仅作用于正文，不作用于代码块与行内代码。

## 输入法组合

- IME 组合期间，组合文本以临时标记态呈现于插入点，不参与语法转换与自动配对；提交时一次性转换为文档事务；取消时移除组合文本。
- 组合期间的光标移动、块切换或文件事件先提交当前组合再执行。

## 格式命令

- 行内格式命令（`inline.bold` / `inline.italic` / `inline.code` / `inline.strike` / `inline.highlight` / `inline.subscript` / `inline.superscript`）对选区统一切换对应标记：未标记则包围，已标记则去除。无选区且位于目标样式内部时解除完整包裹；否则邻近词时先选择整词再格式化，空白或标点位置插入空标记对。
- 块格式命令（`block.paragraph`、`block.heading1`–`block.heading6`、`block.quote`、`block.bulletList`、`block.orderedList`、`block.taskList`）把当前块转换为对应块类型；重复同一命令时返回普通段落（切换语义）。
- 块格式命令覆盖多叶选区时逐叶转换，以一个事务提交，保留逻辑方向和正文端点；标题与段落转换保留既有外层引用、列表容器。
- 文档末尾的格式命令定位最后的实际块；光标已越过终止换行进入末尾空行时，作用于该空行的新段落，不回溯修改前一块或文档首块。
- 含软换行的段落按整个段落转换：标题把软换行合为空格；引用为每行加引用前缀；列表只在首行添加项标记，后续行按列表内容宽度缩进。转换保留正文与行内标记，不只修改插入点所在的源码行。
- `edit.clearFormatting` 作用于选区首尾所属块及中间完整块，去除这些块的行内标记并恢复为段落。

## 自动补全

- 输入触发补全的语法前缀（`[[` 链接、 `[` 引用标签、 `@[` 数学引用、 `!` 图片）时，若注册表存在候选源则弹出候选；无候选源时不弹出。补全提交作为普通事务。
